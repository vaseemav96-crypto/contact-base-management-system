# Contact Base Management System
A simple **Python-based Contact Management System** to manage personal contacts efficiently.
## Features
- **Add Contact** – Store a new contact with name, phone number, and email.  
- **Remove Contact** – Delete a contact by name.  
- **Update Contact** – Update phone number and email of an existing contact.  
- **List Contacts** – View all saved contacts.  
- **Find Contact** – Search for a specific contact by name.  
## Usage
- Run the Python program.  
- A menu will appear:
- Enter the number for your choice and follow the prompts.
